# DU Sky Home

Landing de conversión de Disrupción Urbana, construida con Next.js y optimizada para Vercel.

## Desarrollo local

```bash
npm install
npm run dev
```

Abre `http://localhost:3000`.

## Producción

```bash
npm run build
npm run start
```

En Vercel, importa este repositorio sin cambiar el directorio raíz. Vercel detecta Next.js automáticamente y usa `npm run build`.

Rutas disponibles:

- `/` Landing Sky Home
- `/forms/formulario_skyhome_du_3.html` Formulario Sky Home alternativo
- `/forms/formulario_arquitectura_du.html` Formulario de arquitectura

Los renders se sirven desde `/renders/`.
